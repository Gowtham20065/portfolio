# Boda Gowtham — Systems & Agentic AI Engineer Portfolio

> Production portfolio engineered with React 18, TypeScript, Tailwind CSS, and Vite. Modeled with an archival, high-contrast industrial aesthetic featuring interactive AST parse trees, live concurrency simulators, and an in-browser Linux CLI shell.

---

## ⚡ Technical Architecture

- **Substrate & Theme:** Dark console (`#0A0B09`) paired with subtle Bayer 4x4 matrix grain overlay and high-voltage signal lime (`#B6F23A`).
- **Interactive Canvas:** Custom HTML5 Canvas rendering an interactive Abstract Syntax Tree (AST) node graph with gravitational pointer physics, throttled to 60 FPS and paused when offscreen.
- **Interactive Project Oracles:**
  - **LangGraph AST Pipeline:** Live arithmetic oracle demonstrating how `ast.NodeVisitor` catches LLM arithmetic drift and validates formulas deterministically.
  - **RealEstateHub Concurrency Core:** Live token-bucket simulator demonstrating atomic Redis Lua scripts in memory.
  - **StegoCLI Stream Engine:** Bitwise LSB audio waveform visualizer showing signed int16 masking.
  - **FluxStep Pro:** Topological Directed Acyclic Graph (DAG) layout resolution simulator.
- **Recruiter CLI Shell:** Unix-style command line emulator supporting `cat about`, `cat metrics`, `cat projects`, `download resume`, and `copy brief`.
- **1-Click Recruiter Conversion:** Instant candidate brief copying formatted for hiring manager review.

## 🚀 Quick Start (Local Development)

```bash
# 1. Navigate to project directory
cd gowtham-portfolio

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev
# Open http://localhost:3000 in your browser
```

---

## 📦 Production Build & Preview

```bash
# Compile TypeScript & bundle production assets
npm run build

# Preview production build locally
npm run preview
```

The production output is generated in `./dist` (~70 kB gzipped total payload).

---

## 🌐 Deploy to GitHub Pages (Automated)

1. Push this repository to `https://github.com/gowtham20065/gowtham20065.github.io` (or your repository of choice).
2. Go to **Settings > Pages** on GitHub.
3. Under **Build and deployment > Source**, select **GitHub Actions**.
4. The included `.github/workflows/deploy.yml` workflow will automatically build and publish your portfolio with HTTPS and zero manual steps!
