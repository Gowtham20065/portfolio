This is my personal developer portfolio showcasing my work, projects, technical skills, and research in **deterministic AI agent verification** and **high-concurrency distributed backends**.

---

## 🛠️ Built With

- **Frontend & Core:** React 18, TypeScript, Vite
- **Styling & Design System:** Tailwind CSS (Dark Navy `#0F172A` + Electric Blue `#3B82F6` & Cyan `#06B6D4`)
- **Interactive Visualizations:** HTML5 Canvas (AST node graph with pointer physics), Interactive AST Arithmetic Oracle, Atomic Redis Lua token bucket simulator
- **Icons:** Lucide React
- **Deployment & CI/CD:** GitHub Actions & GitHub Pages

---

## 🚀 Local Development

```bash
# Clone the repository
git clone https://github.com/Gowtham20065/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```
